## 🎯 PROPÓSITO DE LA PRÁCTICA

Familiarizar al estudiante con el lenguaje de programación *JavaScript*, comprendiendo su sintaxis, estructura y aplicación en el desarrollo de páginas web dinámicas.

---

## 🧩 OBJETIVO GENERAL

Conocer la *sintaxis básica de JavaScript* y sus fundamentos para aplicarlos en la creación de scripts funcionales dentro de documentos web.

---

## 🎓 OBJETIVOS ESPECÍFICOS

- Configurar las herramientas para el laboratorio.  
- Elaborar un documento con extensión *.js*.  
- Revisar la *sintaxis básica* dentro de un documento JavaScript.  
- Revisar la *lógica de programación* dentro del lenguaje.  
- Visualizar los resultados obtenidos en el navegador.
